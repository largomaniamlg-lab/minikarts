# MiniKarts 0.2 para Android

Importa project.godot en Godot 4.5.1 y ejecuta la escena principal.
En Android acelera automáticamente: joystick izquierdo para girar y botones de freno, salto, disparo y marcha atrás a la derecha. Recuperar y Nueva carrera arriba. Pista de18m, obstáculos bajos y cajas destructibles.
En escritorio: W/acelerar, A/D/girar, S/freno y reversa, espacio/salto, F/disparo, R/recuperar, Enter/nueva carrera.
Prueba automatizada tests/v02_test.gd con --force-touch.
APK0.2.0 ARM64 usa misma firma de prueba que0.1.3 y actualiza sin desinstalar. No incluye claves privadas.
